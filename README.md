# Furniture E-Commerce Website

### Tech Stack: ReactJs, TailwindCss, Redux-Toolkit, React Router

#### Navbar: 
Includes sections for easy navigation:  
*** Home  
*** Shop  
*** Cart  
*** Wishlist  

#### State Management: 
Utilizes Redux-Toolkit for efficient management of:
*** Adding products to the cart
*** Adding products to the wishlist

#### Styling:
Uses TailwindCSS for a visually appealing and responsive design.

#### React Router:
React Router for features like routing between pages, dynamic routes
